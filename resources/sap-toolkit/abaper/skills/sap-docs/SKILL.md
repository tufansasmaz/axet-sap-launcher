# SAP Documentation Search

Search SAP documentation including:
- ABAP reference (statements, keywords, functions)
- CDS (Core Data Services) views and annotations
- RAP (RESTful Application Programming Model)
- ABAP Cloud best practices
- SAP Community Q&A

## Usage

Simply ask for SAP documentation:
- "How do I create a CDS view in ABAP Cloud?"
- "What is the syntax for SELECT in ABAP SQL?"
- "Show me examples of RAP business objects"
- "ABAP OO class definition syntax"

## Examples

```abap
"Search for CDS view documentation"
"Find examples of @OData.publish annotation"
"ABAP Cloud naming conventions"
"EML statement syntax for RAP"
```
