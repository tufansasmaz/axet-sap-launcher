Calling it yourself

        
    
          
  • Where the token comes from. Signing in to this app stores it in
              the browser. Read it with
              localStorage.getItem('access_token') in the console (F12),
              or use the copy buttons on the curl tab.
    • 
          
  • It lasts 60 minutes. The bar across the top of this page is that
              hour running down. When it turns red, reload and sign in again - a
              401 or a redirect almost always means the clock, not a broken call.
    • 
          
  • The body needs message. Everything else is optional:
              model, max_tokens, temperature,
              system, and context (any object, merged into
              the prompt).
    • 
          
  • Answers cut off at 50 tokens if the flow omits max_tokens.
              That is the enabler node's own default, not a limit on your project.
              This page sends the value in the header field.
    • 
          
  • Two kinds of error look alike. A body with
              "error": true and httpStatus is the platform
              refusing before the flow runs. A body with
              "error": {"code": ...} is the flow answering - your request
              got in.
    • 
          
  • An unknown model name gives you no clue that the name is wrong.
              It fails with a generic 502 llm_gateway_failed, exactly
              like an outage. The models cannot be listed from a browser - that
              lookup needs a server-side key - so the dropdown is a probed list, not
              the project's own. If a name fails, clear the field and try again on
              the app's default.
