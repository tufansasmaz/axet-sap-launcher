# Yerleşik Tarayıcı — uygulama planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajanlar ekranındaki geçişe beşinci seçenek olarak **Tarayıcı**'yı eklemek: alan başına bir `<webview>` ile http/https sayfası açmak, ve sayfanın başlığını, adresini, seçili metnini ve isteğe bağlı ekran görüntüsünü **Ajana gönder** ile seçilen ajanın istem satırına tek adımda yazmak.

**Architecture:**
- **Güvenlik ana süreçte, saf fonksiyonlarla:** `app-electron/main/browserGuard.ts` Electron'a yalnız dar arayüzlerle dokunuyor: webview takma kararı (`allowWebviewAttach`) ve zorla temizlenen ayarlar (`hardenWebviewPreferences`), webview'ın içindeki gezinme/yeni pencere/kısayol kuralları (`installBrowserGuestRules`), `persist:ntt-tarayici` oturumunun izin ve indirme kuralları (`configureBrowserSession`), IPC'ye gelen `webContentsId`'nin doğrulaması (`isOurBrowserGuest`). Hepsi sahtelerle test ediliyor. `windowGuard.ts` bunları `web-contents-created` içinde çağırıyor; `index.ts` yalnız bağımlılıkları veriyor.
- **Gönderme ana süreçte:** renderer yalnız `workspaceId`, `paneId`, `webContentsId` ve "ekran görüntüsü ile" bilgisini yollar (`browser:send`). Ana süreç sayfanın adresini ve başlığını webview'ın kendi webContents'inden okur, seçili metni izole bir betik dünyasında okur, ekran görüntüsünü alan kökünün altına yazar (`browserFiles.ts`), istemi kurar (`buildBrowserPrompt`) ve Görev Panosu'nun yolundan (`agentMonitor.sendPrompt`) gönderir. Akış `browserSend.ts`'te bağımlılık enjeksiyonuyla, Electron'a dokunan ince parça `browserLive.ts`'te.
- **Renderer:** `src/browser/BrowserPage.tsx` (yalnız `<webview>` ve olayları; testlerde sahtesiyle değiştiriliyor), `src/browser/BrowserView.tsx` (araç çubuğu, adres, boş durum, hata gövdesi, çökme, indirme uyarısı, kısayollar), `src/browser/AgentSendMenu.tsx` (Ajana gönder menüsü). Görünüm kaydı mevcut `view` kalıbıyla (`"browser"`) ve yeni `browserUrl` alanıyla.

**Tech Stack:** Electron 44 (`<webview>`, `webContents`, `session`), TypeScript, React 18, Tailwind 3, lucide-react, vitest 2, @testing-library/react (jsdom). Yeni bağımlılık yok.

**Spec:** `docs/superpowers/specs/2026-10-18-tarayici-design.md` (üstüne inşa edilen: `docs/superpowers/plans/2026-10-18-degisiklikler.md`; dal `ozellik/tarayici`, `ozellik/degisiklikler` üstünden)

## Spec'ten bilinçli sapmalar ve netleştirmeler

1. **Tek tarayıcı IPC'si (`browser:send`).** Spec §4.6 "ekran görüntüsü, seçili metin" IPC'lerinden söz ediyor. Plan: renderer yalnız kimlikleri yollar; adres, başlık ve seçili metin ana süreçte webview'ın kendi webContents'inden okunur, istem ana süreçte kurulur. Renderer'ın bildirdiği adres/başlık/metne güvenilmez, yüzey daralır. İki olay kanalı ekleniyor: `browser:downloadBlocked`, `browser:shortcut`.
2. **Seçili metin izole betik dünyasında** (`executeJavaScriptInIsolatedWorld`, sayfanın betikleri `getSelection`'ı değiştiremesin) ve **yalnız ana çerçeveden** okunur; iframe içindeki seçim gelmez. 2 sn'de cevap gelmezse hiçbir şey gönderilmez ("Sayfa cevap vermedi").
3. **"Ekran görüntüsü ile" menüde bir onay kutusu** (`menuitemcheckbox`, ajan listesinin üstünde); ajan seçilince kutunun durumuyla gönderilir. Spec "menüdeki ikinci seçenek" diyor; ajan başına iki satır yerine tek kutu, menüyü yarıya indiriyor.
4. **İstem en çok 4000 UTF-16 birimi** (`sendPrompt`'un sınırı; aşan metni "invalid" diye reddediyor). Adres 2048 kod noktasında `…` ile kırpılıyor; toplam sığmazsa seçili metin 2000'in altına da kısalıyor. Kontrol karakterleri (C0/C1) ve U+2028/U+2029 **boşluğa çevrilip** boşluklar tekleştiriliyor (`sendPrompt` U+2028/2029'u da reddediyor; doğrudan silmek iki kelimeyi birleştirirdi).
5. **Adresteki kullanıcı adı/parola** istemden siliniyor ve son adres olarak config'e yazılmıyor (`readBrowserUrl` reddediyor).
6. **"Ajan çalışıyor" ön kapısı:** `sendPrompt` `running` durumunu denetlemiyor (pano kendi uygunluk kuralını uyguluyor). Ana süreç `browserAgentGate` ile hem başta hem istemden hemen önce denetliyor: kayıt yok → `noAgent`; motor açık değil → `notRunning`; `asking` → `asking`; `running` → `busy`; taslak var → `typing`.
7. **Ekran görüntüsünün kökü alan kaydındaki `root`** (yedek klasör değil). Kök yoksa seçenek kapalı; kök diskte yoksa "kök klasörü yok". Aynı saniyede ikinci görüntü `-2`, `-3` … eki alır (üstüne yazılmaz, `wx`). Kök içindeki `.ntt-studio` bir junction ile dışarıyı gösteriyorsa yazılmaz (Değişiklikler'in `insideRootReal` denetimi).
8. **Başarı satırı "Gönderildi: <ajan>"** (spec "<ajan>'a gönderildi"): Türkçe ek (a/e/ya/ye) ada göre değişiyor, sabit kalıp yanlış ek üretirdi. Ekran görüntüsüyle: "Gönderildi: <ajan> · ekran görüntüsü <dosya>".
9. **Ctrl+L ve Alt+Sol/Sağ sayfa odaktayken de çalışır:** webview'ın tuşları ana pencereye ulaşmıyor; ana süreç webview'ın `before-input-event`'inde yalnız bu üç tuşu yakalayıp ana pencereye `browser:shortcut` olarak iletiyor. Odak uygulamadayken aynı tuşları görünüm kendi `keydown` dinleyicisiyle (yalnız görünürken) karşılıyor. Klavye Kısayolları penceresine iki satır ekleniyor.
10. **Sayfa oturum boyunca takılı kalır:** bir alanda Tarayıcı bir kez açılınca sayfa öbür görünümlerde gizlenir, sökülmez; geri/ileri geçmişi görünüm değişince kaybolmaz. Uygulama kapanınca kaybolur (spec §2). Alan kapatılınca sökülür.
11. **Son adres kendiliğinden yüklenmez:** boş durumda tek tık düğmesi (spec §2); kullanıcı istemeden ağ isteği yok.
12. **`allowpopups` özniteliği var:** olmasaydı `window.open` ana sürecin işleyicisine hiç ulaşmaz, `target=_blank` bağlantıları ölü kalırdı. İşleyici her zaman `deny` döner ve http(s) ise aynı webview'da `loadURL` yapar.
13. **Yükleme hatası sınıfları Chromium hata koduyla:** DNS (-105, -137), bağlantı (-7, -100, -101, -102, -104, -106, -109, -118, -130, -324), sertifika (-200…-299), diğer (kodla). `ERR_ABORTED` (-3; kullanıcı durdurdu ya da yeni gezinme) yok sayılır.
14. **İndirme reddi günlüğe yazılmıyor** (spec §4.7 yalnız iki etiket); kullanıcıya görünümde uyarı.
15. **9 task:** saf mantık (1), güvenlik kararları (2), pencere korumalarına bağlama (3), gönderme akışı + dosya (4), ana süreç bağlantısı + IPC (5), görünüm kaydı (6), görünüm (7), Ajana gönder menüsü (8), rehber + doğrulama (9).

const WEB = /^https?:\/\//i;
// "localhost:5173" şema değil: iki noktadan sonra rakam port demek.
const SCHEME = /^[a-z][a-z0-9+.-]*:(?!\d)/i;
const LOCAL_HOSTS = new Set(["localhost", "127.0.0.1", "[::1]"]);

function parseWeb(raw: string): URL | null {
  try {
    const url = new URL(raw);
    if (url.protocol !== "http:" && url.protocol !== "https:") return null;
    return url.hostname ? url : null;
  } catch {
    return null;
  }
}

/** §4.4: ana çerçeve yalnız ana makinesi olan http/https adresine gidebilir. */
export function isBrowserNavAllowed(raw: unknown): raw is string {
  return typeof raw === "string" && parseWeb(raw) !== null;
}

/**
 * §2: adres alanı. http(s) olduğu gibi; şemasız girdi boşluksuzsa ve nokta ya
 * da localhost içeriyorsa tamamlanıyor (localhost/127.0.0.1/[::1] → http,
 * gerisi https). Başka şema, boşluklu girdi, yol: "scheme". Arama motoruna
 * yönlendirme YOK.
 */
export function normalizeAddress(input: string): AddressResult {
  const text = input.trim();
  if (!text) return { ok: false, reason: "empty" };
  if (text.length > BROWSER_URL_MAX) return { ok: false, reason: "tooLong" };
  let candidate = text;
  if (!WEB.test(text)) {
    if (/\s/.test(text) || SCHEME.test(text) || /^[\\/]/.test(text)) return { ok: false, reason: "scheme" };
    const host = text.split(/[/?#]/, 1)[0].toLowerCase();
    const hostName = host.startsWith("[") ? host.slice(0, host.indexOf("]") + 1) : host.split(":")[0];
    const local = LOCAL_HOSTS.has(hostName);
    if (!local && !hostName.includes(".")) return { ok: false, reason: "scheme" };
    candidate = `${local ? "http" : "https"}://${text}`;
  }
  const url = parseWeb(candidate);
  if (!url) return { ok: false, reason: WEB.test(text) ? "invalid" : "scheme" };
  if (url.href.length > BROWSER_URL_MAX) return { ok: false, reason: "tooLong" };
  return { ok: true, url: url.href };
}

/** §2, §5: kayıttaki son adres. Kullanıcı adı/parola taşıyan adres config'e yazılmıyor. */
export function readBrowserUrl(raw: unknown): string | undefined {
  if (typeof raw !== "string" || raw.length > BROWSER_URL_MAX) return undefined;
  const url = parseWeb(raw);
  if (!url || url.username || url.password) return undefined;
  return raw;
}

function withoutCredentials(raw: string): string {
  const url = parseWeb(raw);
  if (!url || (!url.username && !url.password)) return raw;
  url.username = "";
  url.password = "";
  return url.href;
}

// C0, DEL, C1 ve Unicode satır/paragraf ayırıcıları: sendPrompt bunları reddediyor.
const CONTROL = /[\u0000-\u001f\u007f-\u009f\u2028\u2029]/g;

/** Denetim karakterleri boşluğa, boşluklar tekleşir, `max` kod noktasında "…" ile kırpılır. */
export function cleanText(text: string, max: number): string {
  const flat = text.replace(CONTROL, " ").replace(/\s+/g, " ").trim();
  const points = Array.from(flat);
  if (points.length <= max) return flat;
  return `${points.slice(0, max - 1).join("").trimEnd()}\u2026`;
}

/** UTF-16 bütçesine kod noktası bölmeden sığdırır; sığmazsa boş. */
function fitUnits(text: string, room: number): string {
  if (text.length <= room) return text;
  if (room < 2) return "";
  let out = "";
  for (const ch of text) {
    if (out.length + ch.length > room - 1) break;
    out += ch;
  }
  return `${out.trimEnd()}\u2026`;
}

const SELECTION_FRAME = ' Secili metin: ""'.length;

/**
 * §3: ajanın istem satırına yazılacak TEK satır. `[Tarayici]` öneki `!`/`/`
 * ile başlamayı engelliyor. Toplam BROWSER_PROMPT_MAX'ı aşmıyor: sığmazsa
 * seçili metin kısalıyor.
 */
export function buildBrowserPrompt(input: BrowserPromptInput): string {
  const title = cleanText(input.title, BROWSER_TITLE_MAX);
  const url = cleanText(withoutCredentials(input.url), BROWSER_URL_MAX);
  let text = `[Tarayici] ${title ? `${title} ` : ""}${url}`;
  const tail = input.screenshot ? ` Ekran goruntusu: ${input.screenshot}` : "";
  const selection = fitUnits(cleanText(input.selection, BROWSER_SELECTION_MAX), BROWSER_PROMPT_MAX - text.length - tail.length - SELECTION_FRAME);
  if (selection) text += ` Secili metin: "${selection}"`;
  return text + tail;
}

const pad = (value: number) => String(value).padStart(2, "0");

    `${pad(now.getHours())}${pad(now.getMinutes())}${pad(now.getSeconds())}`;

const CONNECTION_CODES = new Set([-7, -100, -101, -102, -104, -106, -109, -118, -130, -324]);

/** §6: Chromium ağ hata kodu → gövdedeki mesaj. ERR_ABORTED (-3) yeni gezinme ya da Durdur: mesaj yok. */
export function loadErrorKind(code: number): LoadErrorKind | null {
  if (code === -3) return null;
  if (code === -105 || code === -137) return "dns";
  if (code <= -200 && code > -300) return "certificate";
  if (CONNECTION_CODES.has(code)) return "connection";
  return "other";
}

/** §7: Ctrl+L adres alanı, Alt+Sol/Sağ geri/ileri. Başka hiçbir tuş (Ctrl+V dahil) yakalanmıyor. */
export function browserShortcutOf(input: KeyInput): BrowserShortcut | null {
  if (input.type !== undefined && input.type !== "keyDown") return null;
  if (input.shift || input.meta) return null;
  if (input.control && !input.alt && input.key.toLowerCase() === "l") return "focusAddress";
  if (input.alt && !input.control) {
    if (input.key === "ArrowLeft") return "back";
    if (input.key === "ArrowRight") return "forward";
  }
  return null;
}

/**
 * §3: ajan şu an istem alabilir mi? sendPrompt "çalışıyor" durumunu
 * denetlemiyor (pano kendi kuralını uyguluyor); tarayıcı çalışan ajana yazmıyor.
 */
export function browserAgentGate(agent: BrowserAgentPresence | null): BrowserSendFailure | null {
  if (!agent) return "noAgent";
  if (!agent.engineReady || !agent.status || agent.status.state === "finished") return "notRunning";
  if (agent.status.state === "asking") return "asking";
  if (agent.status.state === "running") return "busy";
  if (!agent.inputIdle) return "typing";
  return null;
}

/** §3: ekran görüntüsünün kökü alan kaydındaki `root` (yedek klasör DEĞİL); alan yoksa null. */
export function browserWorkspace(workspaces: readonly SavedTerminalWorkspace[], id: string): { root: string | null } | null {
  const workspace = workspaces.find((w) => w.id === id);
  if (!workspace) return null;
  return { root: workspace.root?.trim() || null };
}

// Yerleşik tarayıcının güvenlik kararları (spec 2026-10-18 tarayici §4).
// Electron'u İÇE AKTARMIYOR: dar arayüzler alıyor, testler sahtelerle
// çağırıyor. Canlı bağlantı windowGuard.ts'te (webview takma ve guest
// kuralları, `web-contents-created`) ve index.ts'te (oturum); orada yalnız
// çağrı var, karar burada.
import { BROWSER_PARTITION, browserShortcutOf, isBrowserNavAllowed, type BrowserShortcut, type KeyInput } from "../shared/browserLogic";

export type BrowserLog = (tag: string, fields: Record<string, string>) => void;

export interface WebviewAttachParams {
  src?: string;
  partition?: string;
}

/**
 * §4.1: yalnız bizim bölüm ve boş ya da http/https başlangıç adresi. Hangi
 * pencerenin taktığı çağıranda denetleniyor (yalnız ana pencere, Flow sandbox
 * asla).
 */
export function allowWebviewAttach(params: WebviewAttachParams | null | undefined): boolean {
  if (!params || params.partition !== BROWSER_PARTITION) return false;
  const src = typeof params.src === "string" ? params.src : "";
  return src === "" || isBrowserNavAllowed(src);
}

const REMOVED_PREFERENCES = ["preload", "preloadURL", "enableBlinkFeatures", "additionalArguments"] as const;
const FORCED_PREFERENCES = {
  nodeIntegration: false,
  nodeIntegrationInSubFrames: false,
  nodeIntegrationInWorker: false,
  contextIsolation: true,
  sandbox: true,
  webSecurity: true,
  allowRunningInsecureContent: false,
  plugins: false,
  webviewTag: false,
  experimentalFeatures: false,
  navigateOnDragDrop: false
} as const;

/** §4.1: renderer ne isterse istesin webview'ın ayarları burada zorlanıyor (Electron'un "webview güvenliği" önerisi). */
export function hardenWebviewPreferences(prefs: Record<string, unknown>): void {
  for (const key of REMOVED_PREFERENCES) delete prefs[key];
  Object.assign(prefs, FORCED_PREFERENCES);
}

interface Preventable {
  preventDefault(): void;
}

export interface GuestContents {
  setWindowOpenHandler(handler: (details: { url: string }) => { action: "deny" }): void;
  loadURL(url: string): Promise<unknown>;
  on(event: "will-navigate", listener: (event: Preventable & { url: string }) => void): unknown;
  on(event: "will-redirect", listener: (event: Preventable & { url: string; isMainFrame: boolean }) => void): unknown;
  on(event: "will-attach-webview", listener: (event: Preventable) => void): unknown;
  on(event: "before-input-event", listener: (event: Preventable, input: KeyInput) => void): unknown;
}

export interface GuestRuleDeps {
  log: BrowserLog;
  onShortcut: (action: BrowserShortcut) => void;
}

function schemeOf(raw: string): string {
  try {
    return new URL(raw).protocol;
  } catch {
    return "gecersiz";
  }
}

/**
 * §4.4: webview'ın kendi webContents'i. Uygulamanın "yalnız kendi sayfası"
 * kuralı YERİNE: ana çerçeve yalnız http/https; yeni pencere asla, http(s)
 * aynı webview'da; webview içinde webview yok; yalnız Ctrl+L ve Alt+Sol/Sağ
 * ana pencereye iletiliyor (sayfa odaktayken uygulama tuşu görmüyor).
 * Günlükte yalnız sonuç ve şema (§4.7).
 */
export function installBrowserGuestRules(contents: GuestContents, deps: GuestRuleDeps): void {
  const decide = (url: string): boolean => {
    const allowed = isBrowserNavAllowed(url);
    try {
      deps.log("tarayici.gezinme", { sonuc: allowed ? "izin" : "ret", sema: schemeOf(url) });
    } catch {
      // günlük hatası kararı değiştirmesin
    }
    return allowed;
  };
  contents.setWindowOpenHandler(({ url }) => {
    if (decide(url)) contents.loadURL(url).catch(() => undefined);
    return { action: "deny" };
  });
  contents.on("will-navigate", (event) => {
    if (!decide(event.url)) event.preventDefault();
  });
  contents.on("will-redirect", (event) => {
    if (!event.isMainFrame) return;
    if (!decide(event.url)) event.preventDefault();
  });
  contents.on("will-attach-webview", (event) => event.preventDefault());
  contents.on("before-input-event", (event, input) => {
    const action = browserShortcutOf(input);
    if (!action) return;
    event.preventDefault();
    deps.onShortcut(action);
  });
}

export interface BrowserSessionLike {
  setPermissionRequestHandler(handler: (webContents: unknown, permission: string, callback: (granted: boolean) => void) => void): void;
  setPermissionCheckHandler(handler: () => boolean): void;
  setDevicePermissionHandler(handler: () => boolean): void;
  on(event: "will-download", listener: (event: Preventable, item: unknown, webContents: { id: number } | null | undefined) => void): unknown;
}

/**
 * §4.3, §4.5: `persist:ntt-tarayici` oturumunda bütün izinler (kamera,
 * mikrofon, konum, bildirim, pano, MIDI, HID, seri port, USB, ekran
 * paylaşımı …) reddediliyor; indirme iptal, kullanıcıya görünümde uyarı.
 */
export function configureBrowserSession(ses: BrowserSessionLike, deps: { onDownloadBlocked: (webContentsId: number | null) => void }): void {
  ses.setPermissionRequestHandler((_webContents, _permission, callback) => callback(false));
  ses.setPermissionCheckHandler(() => false);
  ses.setDevicePermissionHandler(() => false);
  ses.on("will-download", (event, _item, webContents) => {
    event.preventDefault();
    try {
      deps.onDownloadBlocked(typeof webContents?.id === "number" ? webContents.id : null);
    } catch {
      // bildirim düşse de indirme iptal
    }
  });
}

export interface SessionLike {
  getStoragePath(): string | null;
}

export interface GuestCandidate {
  isDestroyed(): boolean;
  getType(): string;
  hostWebContents?: unknown;
  session: SessionLike;
}

/** Aynı nesne ya da aynı (boş olmayan) disk yolu: `persist:` bölümünün kimliği. */
function sameSession(a: SessionLike | null | undefined, b: SessionLike): boolean {
  if (!a) return false;
  if (a === b) return true;
  const storage = a.getStoragePath();
  return !!storage && storage === b.getStoragePath();
}

/** §4.6: IPC'nin verdiği webContentsId ana pencereye bağlı, bu bölümdeki, canlı bir webview mi? */
export function isOurBrowserGuest(candidate: GuestCandidate | null | undefined, host: unknown, browserSession: SessionLike): boolean {
  if (!candidate || !host) return false;
  try {
    return (
      !candidate.isDestroyed() &&
      candidate.getType() === "webview" &&
      candidate.hostWebContents === host &&
      sameSession(candidate.session, browserSession)
    );
  } catch {
    return false;
  }
}

/** `web-contents-created` anında: bu webContents bizim tarayıcının sayfası mı? */
export function isBrowserGuestContents(contents: Pick<GuestCandidate, "getType" | "session">, browserSession: SessionLike): boolean {
  try {
    return contents.getType() === "webview" && sameSession(contents.session, browserSession);
  } catch {
    return false;
  }
}

// sayfa, ajan, dosya ve istem kapıları bağımlılık olarak geliyor; testler

import type { AgentPromptResult } from "./agentMonitor";
import { isBoardId } from "../shared/boardCommands";

  SCREENSHOT_MAX_BYTES,
  SELECTION_TIMEOUT_MS,

  type BrowserSendFailure,
  type BrowserSendResult

  title(): string;
  selection(): Promise<string>;
  capture(): Promise<Uint8Array>;

export interface BrowserSenderDeps {
  workspace(id: string): { root: string | null } | null;
  agent(workspaceId: string, paneId: string): BrowserAgentPresence | null;
  guest(webContentsId: number): BrowserGuestPort | null;

  send(workspaceId: unknown, paneId: unknown, webContentsId: unknown, withScreenshot: unknown): Promise<BrowserSendResult>;

const PROMPT_FAILURE: Record<Exclude<AgentPromptResult, "ok">, BrowserSendFailure> = {
  noAgent: "noAgent",
  notRunning: "notRunning",
  asking: "asking",
  typing: "typing",
  busy: "busy",
  invalid: "invalid",
  writeFailed: "writeFailed"
};

class StepFailure extends Error {
  constructor(readonly reason: BrowserSendFailure) {
    super(reason);
  }
}

function within<T>(promise: Promise<T>, ms: number, reason: BrowserSendFailure): Promise<T> {
  return new Promise<T>((resolve, reject) => {
    const timer = setTimeout(() => reject(new StepFailure(reason)), ms);
    promise.then(
      (value) => {
        clearTimeout(timer);
        resolve(value);
      },
      () => {
        clearTimeout(timer);
        reject(new StepFailure(reason));
      }
    );
  });
}

const validWebContentsId = (value: unknown): value is number =>
  typeof value === "number" && Number.isSafeInteger(value) && value > 0;

export function createBrowserSender(deps: BrowserSenderDeps): BrowserSender {
  const finish = (result: BrowserSendResult, withScreenshot: boolean): BrowserSendResult => {
    try {
      deps.log("tarayici.gonder", { sonuc: result.ok ? "tamam" : result.reason, ekranGoruntusu: withScreenshot });
    } catch {
      // günlük hatası sonucu değiştirmesin
    }
    return result;
  };

  return {
    async send(workspaceId, paneId, webContentsId, withScreenshot) {
      if (!isBoardId(workspaceId) || !isBoardId(paneId) || !validWebContentsId(webContentsId) || typeof withScreenshot !== "boolean") {
        return finish({ ok: false, reason: "invalid" }, false);
      }
      const fail = (reason: BrowserSendFailure) => finish({ ok: false, reason }, withScreenshot);

      const workspace = deps.workspace(workspaceId);
      if (!workspace) return fail("noWorkspace");
      const gate = browserAgentGate(deps.agent(workspaceId, paneId));
      if (gate) return fail(gate);
      const guest = deps.guest(webContentsId);
      if (!guest) return fail("noPage");
      let url: string;
      let title: string;
      try {
        url = guest.url();
        title = guest.title();
      } catch {
        return fail("noPage");
      }
      if (!isBrowserNavAllowed(url)) return fail("noPage");
      const root = workspace.root;
      if (withScreenshot && !root) return fail("noRoot");

      let written: string | null = null;
      try {
        const selection = await within(guest.selection(), SELECTION_TIMEOUT_MS, "pageBusy");
        if (withScreenshot && root) {
          const png = await within(guest.capture(), CAPTURE_TIMEOUT_MS, "captureFailed");
          if (png.byteLength === 0) throw new StepFailure("captureFailed");
          if (png.byteLength > SCREENSHOT_MAX_BYTES) throw new StepFailure("tooLarge");
          const saved = deps.writeScreenshot(root, png, new Date(deps.now()));
          if (!saved.ok) throw new StepFailure(saved.reason);
          written = saved.rel;
        }
        // Seçim ve görüntü sürerken ajan çalışmaya başlamış, soru sormuş ya da kullanıcı yazmaya başlamış olabilir.
        const again = browserAgentGate(deps.agent(workspaceId, paneId));
        if (again) throw new StepFailure(again);
        const text = buildBrowserPrompt({ title, url, selection: typeof selection === "string" ? selection : "", screenshot: written });
        const sent = deps.sendPrompt(paneId, text);
        if (sent !== "ok") throw new StepFailure(PROMPT_FAILURE[sent]);
        return finish({ ok: true, screenshot: written }, withScreenshot);
      } catch (err) {
        if (written && root) {
          try {
            deps.removeScreenshot(root, written);
          } catch {
            // silinemezse olduğu gibi kalır; gönderme zaten durdu
          }
        }
        return fail(err instanceof StepFailure ? err.reason : "writeFailed");
      }
    }
  };
}

// Ekran görüntüsünün diske yazılması (spec 2026-10-18 tarayici §3, §5).
// Yalnız alan kökünün altındaki .ntt-studio/tarayici/ klasörüne, var olan
// dosyanın üstüne yazmadan ("wx"). Kök içindeki bir junction/bağ dışarıyı
// gösteriyorsa yazılmıyor (Değişiklikler'in insideRootReal denetimi; mkdir'den
// önce ve sonra).
import { mkdirSync, statSync, unlinkSync, writeFileSync } from "node:fs";
import path from "node:path";
import { SCREENSHOT_DIR, SCREENSHOT_NAME_TRIES, screenshotRelPath } from "../shared/browserLogic";
import { isSafeRelPath } from "../shared/changesLogic";
import { insideRootReal } from "./changesFs";
import type { ScreenshotWrite } from "./browserSend";

const absolute = (root: string, rel: string) => path.join(root, ...rel.split("/"));

export function writeBrowserScreenshot(root: string, png: Uint8Array, now: Date): ScreenshotWrite {
  try {
    if (!statSync(root).isDirectory()) return { ok: false, reason: "noRoot" };
  } catch {
    return { ok: false, reason: "noRoot" };
  }
  for (let n = 1; n <= SCREENSHOT_NAME_TRIES; n += 1) {
    const rel = screenshotRelPath(now, n);
    if (!isSafeRelPath(rel) || !insideRootReal(root, rel)) return { ok: false, reason: "writeFailed" };
    const file = absolute(root, rel);
    try {
      mkdirSync(path.dirname(file), { recursive: true });
      if (!insideRootReal(root, rel)) return { ok: false, reason: "writeFailed" };
      writeFileSync(file, png, { flag: "wx" });
      return { ok: true, rel };
    } catch (err) {
      if ((err as NodeJS.ErrnoException).code === "EEXIST") continue;
      return { ok: false, reason: "writeFailed" };
    }
  }
  return { ok: false, reason: "writeFailed" };
}

/** Gönderme düşünce kendi yazdığımız görüntüyü geri alıyoruz; tarayıcı klasörü dışına asla. */
export function removeBrowserScreenshot(root: string, rel: string): void {
  if (!isSafeRelPath(rel) || !rel.startsWith(`${SCREENSHOT_DIR}/`) || !insideRootReal(root, rel)) return;
  try {
    unlinkSync(absolute(root, rel));
  } catch {
    // yoksa ya da silinemiyorsa olduğu gibi kalır
  }
}

  useImperativeHandle(
    ref,
    () => ({
      load: (url) => {
        const view = element.current;
        if (!view) return;
        // dom-ready'den önce loadURL fırlatıyor; o anda src yeterli.
        if (ready.current) view.loadURL(url).catch(() => undefined);
        else view.src = url;
      },
      back: () => {
        const view = element.current;
        if (view && ready.current && view.canGoBack()) view.goBack();
      },
      forward: () => {
        const view = element.current;
        if (view && ready.current && view.canGoForward()) view.goForward();
      },
      reload: () => {
        if (ready.current) element.current?.reload();
      },
      stop: () => {
        if (ready.current) element.current?.stop();
      },
      webContentsId: () => (element.current && ready.current ? element.current.getWebContentsId() : null)
    }),
    []
  );

  useEffect(() => {
    const view = element.current;
    if (!view) return;
    const push = () => {
      if (!ready.current) return;
      try {
        handlers.current.onState({
          url: view.getURL(),
          title: view.getTitle(),
          loading: view.isLoading(),
          canGoBack: view.canGoBack(),
          canGoForward: view.canGoForward()
        });
      } catch {
        // webview sökülürken
      }
    };
    const onDomReady = () => {
      if (!ready.current) {
        ready.current = true;
        handlers.current.onReady(view.getWebContentsId());
      }
      push();
    };
    const onFailLoad = (event: Event) => {
      const fail = event as FailEvent;
      if (fail.isMainFrame) handlers.current.onFail(fail.errorCode, fail.validatedURL);
    };
    const onGone = () => handlers.current.onCrash();
    view.addEventListener("dom-ready", onDomReady);
    for (const name of STATE_EVENTS) view.addEventListener(name, push);
    view.addEventListener("did-fail-load", onFailLoad);
    view.addEventListener("render-process-gone", onGone);
    return () => {
      view.removeEventListener("dom-ready", onDomReady);
      for (const name of STATE_EVENTS) view.removeEventListener(name, push);
      view.removeEventListener("did-fail-load", onFailLoad);
      view.removeEventListener("render-process-gone", onGone);
    };
  }, []);

  return (
    <webview
      ref={element as unknown as Ref<HTMLWebViewElement>}
      src={src}
      partition={BROWSER_PARTITION}
      allowpopups={"true" as unknown as boolean}
      className="h-full w-full"
    />
  );
});

export default BrowserPage;

    if (action === "focusAddress") {
      inputRef.current?.focus();
      inputRef.current?.select();
      return;
    }
    setFailure(null);
    setCrashed(false);
    if (action === "back") pageRef.current?.back();
    else pageRef.current?.forward();
  };

    if (failure) {
      open(failure.url);
      return;
    }
    setCrashed(false);
    pageRef.current?.reload();

      if (id === latest.current.webContentsId) latest.current.run(action);

      const mine = id === null ? latest.current.visible : id === latest.current.webContentsId;

        meta: event.metaKey

          className={ICON_BUTTON}

            )}
          </>
        )}
      </div>
    </section>
  );
}

9. **Şema:** adres alanına `file:///C:/Windows/win.ini`, `javascript:alert(1)`, `sap fiori` yaz → "Yalnız http ve https adresleri açılır." ve gezinme olmamalı.

11. **Takılı kalma:** Bölmeler'e geçip Tarayıcı'ya dön → aynı sayfa, Geri çalışıyor. Uygulamayı kapatıp aç → boş durumda "Son açılan: …" düğmesi; tıklayınca açılmalı.
